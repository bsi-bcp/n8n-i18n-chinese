## 根因取证（module.descriptor.ts 2.39.8 → 2.40.3）

上游把模块定义 API 整体重构（**语义重构，非文案变化**——projectTabs/resources 目标行逐字未变）：

1. `import { type FrontendModuleDescription }` → `import { defineFrontendModule }`
2. `export const DataTableModule: FrontendModuleDescription = {...}` → `export const DataTableModule = defineFrontendModule({...})`
3. insights 动态导入迁至独立包 `@n8n/frontend-module-insights`

git apply 失效的是**包装结构上下文**，而非补丁的目标语义行（`displayName: 'Data Table'` / `label: i18n.baseText(...)` 两代写法完全一致）——这正是改用语义脚本（精确文本替换）的依据：脚本匹配目标行本身，对包装结构免疫。
