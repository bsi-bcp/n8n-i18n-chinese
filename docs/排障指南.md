# n8n 中文版排障指南

> 按症状索引。先查这里，解决不了再走「错译反馈」的 Issue 渠道（技术故障类问题同样适用）。

## 1. 拉取镜像报 401 / 拉不到

- 本镜像仓库为**公开拉取**，不需要 `docker login`。如果之前执行过 `docker login registry.bcpcloud.cn` 等旧仓库，旧凭证可能干扰：
  ```bash
  docker logout swr.cn-north-4.myhuaweicloud.com
  docker pull swr.cn-north-4.myhuaweicloud.com/bcphub/n8n-chinese:<版本号>
  ```
- 确认版本号存在：见 README 兼容矩阵 / Releases 页

## 2. 打开界面白屏

- **原因**：editor-ui（前端）与 n8n 后端版本错配过大
- **处理**：按 README「n8n 版本兼容说明」矩阵，换成与后端**精确匹配或就近**的汉化包/镜像；白屏本身不会损坏数据，换对版本即恢复

## 3. 界面大部分中文，但部分功能是英文

按英文出现的位置对号入座：

| 位置 | 原因 | 处理 |
|---|---|---|
| 新装/升级后新功能的界面 | 汉化包版本低于后端版本 | 升级到与后端匹配的汉化包（或等我们跟版） |
| **第三方社区节点**（飞书、其他社区包）的参数面板 | 社区节点是第三方开发，不在汉化范围 | 正常现象；向节点作者反馈或等其自带中文 |
| 自己绕过我们直接升级了 n8n | 新版界面文案还没进词典 | 等本仓库跟版发版（通常数天内） |

## 4. Code 节点执行失败（Queue Mode 集群）

- 检查 runners 容器是否在运行、且**版本与 n8n 主服务严格一致**（如都是 2.39.8）——版本错配会导致执行静默失败
- `docker logs <runners容器名>` 看具体报错

## 5. 升级后 n8n 无法启动 / 数据库报错

- **minor 跨级升级**（如 2.39.x → 2.40.x）会执行数据库迁移，**官方不支持直接降级**
- 升级前必做：备份 compose 文件 + 数据卷；回滚需按官方指南执行 `n8n db:revert`（一次回退一步）后再回旧镜像
- 升级失败先看容器日志定位，再决定回滚或前滚修复

## 6. 升级后社区节点报 `Cannot find module`

- n8n 2.38.4 起不再向社区节点提供内置模块（`ajv`/`axios`/`glob` 等）
- 处理：在各社区节点包目录内 `npm install --no-save <缺失模块>` 后重启容器；升级前先盘点实例装了哪些社区节点

## 7. 镜像拉取很慢 / 超时

- 华为云 SWR 境内直连通常秒级；跨运营商/海外节点可能慢，属网络环境问题
- 大镜像（Queue Mode runners 约 2GB）首次拉取较慢，后续有本地缓存

## 8. 反馈渠道

- **译文错误**（错译/漏译/术语）：README「错译反馈」节 → GitHub Issues
- **技术故障**：同样走 Issues，附 `docker logs` 相关片段与版本号
- 反馈进入翻译评审登记，随下个版本修复
